# Asset logos

Optional. Drop a logo here named by its symbol - `SPY.svg`, `QQQ.svg`,
`AAPL.svg`, `AMZN.svg`, `MSFT.svg`, `NVDA.svg`, `GOOGL.svg`, `TSLA.svg`,
`BTC.svg`, `XAU.svg` (or .png / .webp, square, at least 64x64) - and the next
build uses it in the ticker, the dashboard and the Invest screen. Any asset
without a file keeps its drawn badge from `public/js/assets.js`.

Company logos are their owners' trademarks: use them only where you have the
right to.
